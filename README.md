# Your Week in One Line

Deterministic `program/v1` entry for the [make.fun "Your Week in One Line" bounty](https://make.fun/r/41fw6r6c) (`u-boge-your-week-in-one-line-d1c14ced`).

## Usage

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Writes a single-line UTF-8 entry (`<= 100` characters, zero trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` during local testing).
